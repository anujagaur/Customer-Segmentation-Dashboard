# 📊 Customer Segmentation Dashboard

## Overview
This project is an interactive Power BI dashboard designed to analyze customer purchasing behavior using **RFM (Recency, Frequency, Monetary) Analysis**. It helps businesses identify valuable customer segments and make data-driven marketing decisions.

## Features
- Interactive Power BI dashboard
- Customer segmentation using RFM Analysis
- KPI Cards for Revenue, Customers, Orders, and Average Order Value
- Revenue by Customer Segment
- Customer Distribution Analysis
- Dynamic filters and slicers
- Business insights for targeted marketing and customer retention

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel
- RFM Analysis

## Dataset
The dashboard is built using an Online Retail transaction dataset containing customer purchase history, order dates, quantities, and sales information.

## Project Files
- `customer_segmentation_Dashboard.pbix` – Power BI Dashboard
- `OnlineRetail (2).xlsx` – Dataset
- `Dashboard_README.pdf` – Project Documentation

## Key Insights
- Identifies high-value customers.
- Detects customers at risk of churn.
- Supports customer retention strategies.
- Helps businesses improve marketing effectiveness.
